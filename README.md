# Каталог користувачів із API

Невелике домашнє завдання на React + TypeScript. Логіка та інтерфейс User розміщені в `src/App.tsx`, оформлення — звичайний CSS.

## Запуск

```bash
npm install
npm run dev
```

Перевірка типів і збірка: `npm run build`.

## Як працює

- useEffect із залежностями `[]` завантажує користувачів через fetch.
- Відображаються завантаження, помилка або картки користувачів.
- Пошук за ім’ям працює через filter без урахування регістру та без додаткових запитів.
- Функція очищення викликає abort. Скасований запит не показує помилку й не оновлює стан.
- У режимі розробки StrictMode може запустити ефект двічі: перший запит буде скасовано. Це не пов’язано з пошуком.

API: https://jsonplaceholder.typicode.com/users

## Ручна перевірка

1. Відкрийте Network у DevTools та перезавантажте сторінку з повільним з’єднанням — спочатку видно завантаження, потім картки.
2. Введіть `leanne`, потім неіснуюче ім’я: результати змінюються, нових запитів немає.
3. Увімкніть Offline та перезавантажте сторінку — з’явиться повідомлення про помилку.
